frijoles flags ls — every flag, and what each environment serves

Usage
  frijoles flags ls [--project <slug>] [--json]

Each environment says on or off, exactly as the flags page does: on when the app gets
  true, off when it gets false or nothing. A flag that is not on/off shows the value it serves.
  Switch one with `frijoles flags set <key> --value true|false` or `frijoles flags kill <key>`.

Flags
  --project <slug>  the project (default: the remembered one)

Exit codes
  0  ok         it worked
  1  usage      the command is wrong — nothing was sent
  2  auth       the credential is not accepted — run `frijoles login`
  3  not-found  no such thing, or not yours
  4  conflict   someone else changed it — re-read and retry
  5  partial    some environments changed and some did not
  6  server     the server or the network is unwell — retry
