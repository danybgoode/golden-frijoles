frijoles login — sign this machine in (browser), or save a CLI token

Usage
  frijoles login [--token <token>] [--api <url>]

At a terminal, opens your browser: confirm the code it shows and this machine
  is signed in. If browser sign-in is not available, it asks for a token instead — mint
  one in the console under Setup › CLI access and paste it.

  With --token, or a token piped in, no browser is involved. A pasted token is read
  from STDIN — so it never appears in your shell history or in `ps`. For CI, set
  GOLDEN_FRIJOLES_TOKEN instead and skip this verb; nothing is written to disk in that case.

Flags
  --token <token>  the token, instead of reading stdin
  --api <url>      the deployment (default: https://goldenfrijoles.com)

Exit codes
  0  ok         it worked
  1  usage      the command is wrong — nothing was sent
  2  auth       the credential is not accepted — run `frijoles login`
  3  not-found  no such thing, or not yours
  4  conflict   someone else changed it — re-read and retry
  5  partial    some environments changed and some did not
  6  server     the server or the network is unwell — retry
