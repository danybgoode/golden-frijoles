frijoles projects delete — delete a product you own: gone at once, its keys stop working, its data kept 30 days

Usage
  frijoles projects delete <slug> --confirm <slug> [--json]

Owner only. The product leaves every list, and every key, connector URL and share link it
  issued stops working, at once. Its data is kept, and its name stays taken, until you run
  `frijoles projects purge` 30 days later. The public golden-frijoles product cannot be deleted.
  --confirm must repeat the name.

Flags
  --confirm <slug>  the same name again — nothing happens without it

Exit codes
  0  ok         it worked
  1  usage      the command is wrong — nothing was sent
  2  auth       the credential is not accepted — run `frijoles login`
  3  not-found  no such thing, or not yours
  4  conflict   someone else changed it — re-read and retry
  5  partial    some environments changed and some did not
  6  server     the server or the network is unwell — retry
