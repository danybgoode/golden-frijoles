frijoles experiments show — an experiment's results, any day: the counts, the chance, what to do next

Usage
  frijoles experiments show <key> [--project <slug>] [--json]

The same reading the console's results page shows. `readout.chance` is how likely the leading version is
  really better (0–1), at any volume; `readout.verdict.actions` is what may be done now.

Flags
  --project <slug>  the project (default: the remembered one)

Exit codes
  0  ok         it worked
  1  usage      the command is wrong — nothing was sent
  2  auth       the credential is not accepted — run `frijoles login`
  3  not-found  no such thing, or not yours
  4  conflict   someone else changed it — re-read and retry
  5  partial    some environments changed and some did not
  6  server     the server or the network is unwell — retry
