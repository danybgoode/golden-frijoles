frijoles projects create — make a new product (idempotent: one you already own is left alone)

Usage
  frijoles projects create <slug> [--json]

Makes a product called <slug> in your own workspace, with you as its owner.
  A name you already own answers created: false and changes nothing, so a script can
  run it twice. A name anyone else holds is a conflict.

  It does not bind a repo to the product — `frijoles init --create <slug>` does both —
  and it never returns an ingest key: `frijoles keys create --type ingest` makes one, with
  its own confirmation and its own audit row.

Exit codes
  0  ok         it worked
  1  usage      the command is wrong — nothing was sent
  2  auth       the credential is not accepted — run `frijoles login`
  3  not-found  no such thing, or not yours
  4  conflict   someone else changed it — re-read and retry
  5  partial    some environments changed and some did not
  6  server     the server or the network is unwell — retry
