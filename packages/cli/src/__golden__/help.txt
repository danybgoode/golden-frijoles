frijoles — the Golden Frijoles CLI

  Create a flag in every environment, roll it out, and kill it, from a terminal
  or from an agent. Every command takes --json.

Usage
  frijoles <command> [flags]

Commands
  login                     sign this machine in (browser), or save a CLI token
  logout                    forget the saved token on this machine
  whoami                    the account, the credential and the projects it reaches
  doctor                    why is it not working — every check, in order
  setup                     answer the setup questions (each has a default; only the first is required)
  init                      project, key, .env.local and the snippet — in one verb
  status                    has the project received its first event yet, and which was the latest
  horizon                   the product's destinations and the epics that light each
  funnel                    a feature's funnel by month or week: got it, adopted, retained

  config
  config list               every setting in golden-frijoles.config.json and the legacy files, and which files each section came from
  config get                one setting's effective value (or its default when nothing sets it)
  config set                change one setting in golden-frijoles.config.json

  projects
  projects ls               the projects this credential reaches
  projects create           make a new product (idempotent: one you already own is left alone)
  projects use              remember which project the other commands act on
  projects delete           delete a product you own: gone at once, its keys stop working, its data kept 30 days
  projects purge            remove a product deleted 30+ days ago, and all its data, for good

  flags
  flags ls                  every flag, and what each environment serves
  flags get                 one flag: its definition, its versions and who changed it
  flags create              create a flag, with a polarity, in the environments you name
  flags set                 change which variant a flag serves by default
  flags rollout             serve a flag to a percentage of contexts
  flags rules               replace a flag’s targeting rules from a file
  flags kill                the 3am verb — serve false, and clear every rule
  flags diff                what changed between two versions, in words
  flags history             every version of a flag, and who changed what
  flags sync                publish a flag catalog from source control

  north-star
  north-star set            send a North Star workshop's metric and inputs to the project
  north-star readings       one North Star input's readings, and the latest on or before a day

  scenarios
  scenarios ls              targets, scenario definitions and runs
  scenarios targets add     register an app origin as a drill target
  scenarios targets verify  check that the app answers with the target token
  scenarios targets revoke  stop an app origin being a drill target
  scenarios define          define a drill: a target, a fault flag version and its bounds
  scenarios launch          start a run of the newest version of a scenario
  scenarios stop            stop a run now
  scenarios runs            runs, and with --watch their progress until they end

  bet
  bet sync                  create the bet's flag from its epic (a Measure flag, off until you roll it out)

  experiments
  experiments decision      an experiment's decision record (the latest version unless --version)

  keys
  keys ls                   every credential that can reach this project
  keys create               mint a credential — the kind is required, never guessed
  keys revoke               kill a credential, immediately and permanently

Global flags
  --json                 machine-readable output on stdout, and nothing else
  --project <slug>       act on this project (default: the one from `frijoles projects use`)
  --api <url>            the deployment to talk to (default: the one you logged in to)
  --token <token>        use this credential instead of the saved one
  --help, -h             this text, or a verb's own
  --version, -V          print the version and exit

Environment
  GOLDEN_FRIJOLES_TOKEN    a CLI token. Wins over the saved credential — this is the CI path,
                           and it means CI never has to write a token to disk.
  GOLDEN_FRIJOLES_URL      the deployment to talk to.
  GOLDEN_FRIJOLES_PROJECT  the active project.

Exit codes
  0  ok         it worked
  1  usage      the command is wrong — nothing was sent
  2  auth       the credential is not accepted — run `frijoles login`
  3  not-found  no such thing, or not yours
  4  conflict   someone else changed it — re-read and retry
  5  partial    some environments changed and some did not
  6  server     the server or the network is unwell — retry
