frijoles init — project, key, .env.local and the snippet — in one verb

Usage
  frijoles init [--project <slug> | --create <slug>] [--env <environment>] [--ingest] [--json] [--yes]

Binds this repo to a product — written as project.slug in golden-frijoles.config.json,
  which every later command in the repo reads. --project <slug> picks one you belong to;
  --create <slug> makes it first. With neither, a repo already bound keeps its product;
  otherwise it asks at a terminal, and under --json it stops and names both flags.

  Idempotent. Re-running it does not mint a second key when .env.local already
  carries one; it says so and leaves the file alone.

  ⚠️ It REFUSES if it cannot get .env.local into .gitignore. A live credential in a
  tracked file is the failure this verb exists to prevent, so it will not create one and
  then warn about it.

Flags
  --env <environment>  development | preview | production (default: development)
  --project <slug>     bind this repo to a product you belong to
  --create <slug>      make the product first, then bind this repo to it
  --ingest             also write an ingest key (GROWTH_ENGINE_API_KEY) for sending events; kept when it is already a live key of the project
  --yes                accepted and ignored — name the product with --project or --create instead

Exit codes
  0  ok         it worked
  1  usage      the command is wrong — nothing was sent
  2  auth       the credential is not accepted — run `frijoles login`
  3  not-found  no such thing, or not yours
  4  conflict   someone else changed it — re-read and retry
  5  partial    some environments changed and some did not
  6  server     the server or the network is unwell — retry
