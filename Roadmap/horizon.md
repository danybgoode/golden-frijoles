# Horizon

The end states Golden Frijoles is walking toward, in display order. An epic lights one with `destination: <id>` (or a
comma-separated list) in its README frontmatter; `roadmap-push` sends this list and the Hub's `/horizon` page reads it.

## byo-agent-frontdoor — The BYO-agent front door
Copy-your-MCP-URL, a real self-serve signup, and a live TARS/North Star/A-B demo — the front door a technical PM lands on.

## inverted-loop — The inverted loop
Signals become structured tasks — and your own agent closes them, not ours.

## pods-proof — Pods & proof (ROI)
The cost-center-to-revenue-engine sales artifact: velocity, DORA, cost-per-shipped-point — benchmarked, never claimed.

## primitives-grid — The full primitives grid
Telemetry, feature registry, TARS, North Star, experiments, and entity journeys as one operable set.

## self-serve-tenancy — Self-serve tenancy & pricing
Self-serve tiers and hand-provisioned pod engagements, live behind real signup.

## agent-legible-surface — An agent-legible surface
Docs, status, and a manifest an agent can read as easily as a human can.
